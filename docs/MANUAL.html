SO-101 Control Station — User ManualSO-101 Control Station — ユーザーマニュアル

A step-by-step guide for two robots — the Feetech SO-101 / SO-ARM100 and the Damiao reBot B601-DM — from an unopened kit to a calibrated, teleoperated arm, with a screenshot of every screen you will meet.

2種類のロボット（Feetech SO-101 / SO-ARM100 と Damiao reBot B601-DM）を、開封直後から「キャリブレーション済みで遠隔操作できる」状態にするまでの手順書です。実際に表示される各画面のスクリーンショット付き。

v0.2.0Setup → Calibration → Drive2 robots, 1 window2台のロボット、1つのウィンドウ

Before you startはじめに

This app drives two robots from one window: the SO-101 / SO-ARM100 (Feetech STS3215 servos) and the reBot B601-DM (Damiao CAN motors, with Seeed's Star Arm 102 as its leader). It does not need the full LeRobot package (no PyTorch, no dataset stack). You need Python 3.10+ and the robot itself. For the SO-101 that is the arm, a USB serial adapter and — the single most common "my arm is dead" cause — the arm's own 5 V power supply: USB alone powers the adapter, not the servos. The B601-DM needs a USB-to-CAN adapter for the follower and, for teleoperation, the Star Arm 102 on its own USB-serial port.

本アプリは1つのウィンドウで2種類のロボットを扱います：SO-101 / SO-ARM100（Feetech STS3215サーボ）と reBot B601-DM（Damiao CANモーター。リーダーはSeeedのStar Arm 102）。LeRobot本体（PyTorchやデータセット関連）は不要です。必要なのはPython 3.10以降とロボット本体です。SO-101の場合は、アーム、USBシリアルアダプタ、そして「アームが全く反応しない」原因で最も多い、アーム本体用の5V電源です（USB給電ではアダプタしか動かず、サーボは動きません）。B601-DM の場合はフォロワー用のUSB-CANアダプタと、遠隔操作用にStar Arm 102（専用のUSBシリアルポート）が必要です。

git clone https://github.com/HaikalBaiqunni/so101-control-station.git
cd so101-control-station
python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
python main.py

The app opens on the stage: a 3D digital twin with the controls floating over it. Both robots ship with a twin model, so it loads by itself. Pick the robot in the top-left corner; everything below says which robot a section is for.

アプリはステージで起動します。3Dのデジタルツインの上に操作パネルが浮かぶ構成です。どちらのロボットにもツインのモデルが同梱されているため、自動で読み込まれます。左上でロボットを選びます。以降の各節に、どちらのロボット向けかを明記しています。

ⓘ

None of the screenshots were taken with hardware connected. In the ones that show "Follower online" or a leader ghost, the connection state and poses are simulated to show the layout.

スクリーンショットはいずれも実機を接続せずに撮影しています。「Follower online」やリーダーのゴーストが表示されている画面は、レイアウトを示すために接続状態と姿勢を模擬したものです。

02

Set up the SO-101SO-101のセットアップ

The SO-101 has to be prepared in order: give every servo its own id, calibrate the arm, then drive it. All of it lives in the Setup hub (top bar → Setup). Back to stage returns to the twin.

SO-101は順番どおりに準備します：各サーボにIDを割り当て、アームをキャリブレーションし、その後に操作します。すべてSetupハブ（トップバー → Setup）にあります。Back to stageでツインに戻れます。

Motors and ids — give each servo an IDMotors and ids — 各サーボにIDを割り当てる

Every STS3215 leaves the factory answering to id 1. Six of them on one bus are electrically fine but logically identical: a read addressed to id 1 gets six colliding replies. Nothing else works until each servo has its own address.

すべてのSTS3215は工場出荷時にID 1で応答します。6台を1本のバスに繋いでも電気的には問題ありませんが、論理的には区別できません。ID 1宛ての読み取りには6台分の応答が衝突して返ります。各サーボに固有のアドレスを割り当てるまで、他の機能は動きません。

1

Connect to the busバスに接続する

Pick the USB serial adapter's port (the label names the chip: CH340 / CH343 / CP210x / FTDI, which tells it apart from an unrelated COM port) and click Connect. No calibration file is needed here.

USBシリアルアダプタのポートを選びます（ラベルにチップ名 CH340 / CH343 / CP210x / FTDI が出るので、無関係なCOMポートと区別できます）。Connectをクリック。この段階ではキャリブレーションファイルは不要です。

2

Scan for servosサーボをスキャンする

Scan bus (all baudrates) sweeps all eight Feetech baudrates and ids 0–20, so a servo somebody reconfigured still shows up. Quick rescan (1 Mbps) checks only the rate this app uses. Deep scan (ids 0–253) is the last resort for a servo at an unexpected id. In the Arm status table a joint turns green (OK) when it answers at the expected id and baudrate, amber if it is alive on the wrong baudrate, and red (missing) if it never answered.

Scan bus (all baudrates)はFeetechの8種類のボーレートとID 0〜20を走査するので、以前に別設定にされたサーボも見つかります。Quick rescan (1 Mbps)は本アプリが使うレートだけを確認します。Deep scan (ids 0–253)は想定外のIDにいるサーボを探す最終手段です。Arm statusテーブルでは、想定のIDとボーレートで応答すると緑（OK）、生きているがボーレートが違うと黄色、一度も応答しないと赤（missing）になります。

3

Assign the connected servo's ID接続中のサーボにIDを割り当てる

⚠

Plug in exactly one servo for this step. Every servo answers to id 1 out of the box, so with several attached they would all take the new id at once and stay indistinguishable. That is why Assign this id to the connected servo is enabled only while the scan sees a single servo.

この手順では必ず1台だけサーボを接続してください。出荷時はすべてID 1で応答するため、複数台を繋ぐと全台が同時に新しいIDを受け取り、区別できないままになります。Assign this id to the connected servoが、スキャン結果が1台のときだけ有効になるのはそのためです。

Choose which joint this servo becomes (the first joint still missing is preselected, so going 1→6 needs no fiddling) and click Assign. A servo on the wrong baudrate can be moved back to 1 Mbps with Set servo baudrate. Repeat with the next raw servo until all six are OK.

このサーボをどのジョイントにするか選びます（まだ不足している最初のジョイントが自動選択されるので、1→6の順なら操作不要）。Assignをクリック。ボーレートが違うサーボはSet servo baudrateで1 Mbpsに戻せます。次の未設定サーボで繰り返し、6台すべてがOKになるまで続けます。

✓

This is the in-app equivalent of lerobot-setup-motors.

これは lerobot-setup-motors のアプリ内版に相当します。

Calibration — record what “middle” and “as far as it goes” meanCalibration — 「中央」と「可動範囲の限界」を記録する

A servo's raw encoder count (0–4095) says nothing about the joint's real position until two things are fixed: where its zero is (the homing offset) and how far it may travel (min / max limits). Calibration records both per joint into one LeRobot-format .json, following lerobot-calibrate's own sequence.

サーボの生のエンコーダ値（0〜4095）は、ゼロ点（ホーミングオフセット）と可動範囲（最小・最大リミット）が決まるまで、ジョイントの実際の位置を意味しません。Calibrationはこの2つをジョイントごとにLeRobot形式の.jsonへ記録します。手順はlerobot-calibrateと同じです。

Choose the Role (Follower or Leader — a leader needs its own file), untick any joint that is not plugged in, pick the port and Connect. The five buttons unlock one at a time; Reset is always clickable as the way to start over.

Role（FollowerかLeader。リーダーにも専用ファイルが必要）を選び、接続していないジョイントのチェックを外し、ポートを選んでConnectします。5つのボタンは1つずつ解放され、Resetだけは「やり直し」用に常にクリックできます。

⚠

The gripper needs care. The sweep assumes the joint's hard stop is its real limit. A belt- or rack-driven gripper runs into a freewheel zone past its real extremes, so the sweep records a near-360° range. Use one of the two helpers under the step buttons: manual 2-point capture (park it fully closed, click Capture gripper CLOSED, then fully open) or Auto-calibrate (stall-safe), which drives to both extremes at reduced torque and stops the moment it stalls. Do not disconnect during Auto-calibrate: restoring full torque mid-search can leave the goal past the real wall.

グリッパーには注意が必要です。スイープは、ジョイントの物理ストッパーが実際の限界だと仮定します。ベルト駆動やラック駆動のグリッパーは実際の限界を超えるとフリーホイール状態になり、ほぼ360°の範囲が記録されてしまいます。ステップボタンの下にある2つの方法を使ってください：manual 2-point capture（完全に閉じた状態でCapture gripper CLOSED、次に完全に開いた状態で同様に）、またはAuto-calibrate (stall-safe)（低トルクで両端まで動き、失速した瞬間に停止）。Auto-calibrate中に切断しないでください。探索の途中でフルトルクに戻ると、目標が実際の壁の先に残る場合があります。

Keep the saved file: you point the Connection card at it every session. Files are interchangeable with lerobot-teleoperate and lerobot-record in both directions.

保存したファイルは大切に保管してください。セッションごとにConnectionカードでこのファイルを指定します。ファイルはlerobot-teleoperateやlerobot-recordと双方向に共有できます。

Inputs, and Data and logsInputs と Data and logs

Inputs shows the gamepad status and mapping, and the keyboard jog key caps, which light up while a key is held. Data and logs shows where this session's log file is and opens its folder; the telemetry CSV log is started from the Telemetry drawer.

Inputsにはゲームパッドの状態と割り当て、キーボードジョグのキーキャップ（押している間点灯）があります。Data and logsではこのセッションのログファイルの場所を確認し、フォルダを開けます。テレメトリのCSVログはTelemetryドロワーから開始します。

03

Set up the reBot B601-DMreBot B601-DMのセットアップ

The B601-DM is a different machine underneath: Damiao motors on a CAN bus, and a leader (Star Arm 102) that is not Damiao at all but FashionStar UART servos on its own USB port. Switch the Robot picker to reBot B601-DM; the Setup hub then shows the Damiao tools.

B601-DMは内部が別物です：CANバス上のDamiaoモーターと、Damiaoではなく専用USBポートのFashionStar UARTサーボで構成されたリーダー（Star Arm 102）です。Robot選択をreBot B601-DMに切り替えると、SetupハブにDamiao用のツールが表示されます。

Motors and ids — CAN idsMotors and ids — CANのID

Every Damiao motor ships answering to the same default id, so several on one bus cannot be told apart. Give each its own id, one motor at a time: the CAN id is the motor's 1-based position in the arm (joint1 = 01 … finger_left = 07) and the master id is the CAN id + 0x10.

Damiaoのモーターは出荷時にすべて同じIDで応答するため、複数台を1本のバスに繋ぐと区別できません。1台ずつ固有のIDを割り当てます。CAN IDはアーム内での1始まりの位置（joint1 = 01 … finger_left = 07）、マスターIDはCAN ID + 0x10です。

⚠

No hot-plugging. Cut power before connecting or disconnecting the XT30 2+2 interface, as Seeed's own safety notes say. Unlike Feetech's servos, this connector is not rated for it.

活線挿抜は禁止です。Seeed公式の安全上の注意のとおり、XT30 2+2コネクタを抜き差しする前に電源を切ってください。Feetechのサーボと違い、このコネクタは活線挿抜に対応していません。

1

Connect to the adapterアダプタに接続する

Pick the USB-serial adapter Damiao's own DM_Tools uses (921 600 baud, fixed) and Connect.

Damiao純正DM_Toolsと同じUSBシリアルアダプタを選び（921 600 baud固定）、Connectします。

2

Probe the one connected motor接続した1台をプローブ

Enter the motor's current id in hex (usually 01) and click Probe. With one motor on the bus it answers "found".

モーターの現在のIDを16進数で入力し（通常は01）、Probeをクリック。バス上が1台なら「found」と応答します。

3

Give it a unique id固有のIDを割り当てる

Pick which joint it is; the suggested id and master id are filled in. Assign to the connected motor asks for confirmation and writes the motor's flash. Unplug it, chain the next motor on, and repeat.

どのジョイントか選ぶと、推奨のIDとマスターIDが入力されます。Assign to the connected motorは確認のあとモーターのフラッシュに書き込みます。取り外して次のモーターを繋ぎ、繰り返します。

4

Verify the whole armアーム全体を検証

With all seven wired, Verify All reads every id back in one pass; the Motor status table shows OK or NO RESPONSE per joint.

7台すべてを配線した状態でVerify Allを押すと、全IDを一度に読み戻し、Motor statusテーブルにジョイントごとのOKまたはNO RESPONSEが表示されます。

Section 4 (Motor state & PID) works on the motor the last Probe found: Enable and Disable the motor's own loop, Set Zero to save its current pose as its zero in flash (park the arm where you want zero first), and Read PID / Write PID for the onboard gains. Write PID stays disabled until a Read succeeds, so fields showing 0 can never be written by accident.

セクション4（Motor state & PID）は、直近のProbeで見つかったモーターに作用します：Enable / Disableでモーター自身の制御ループを入切、Set Zeroで現在の姿勢をゼロ点としてフラッシュに保存（先に、ゼロにしたい位置へアームを置いてください）、Read PID / Write PIDで内蔵ゲインを読み書きします。Write PIDはReadに成功するまで無効なので、0表示のまま書き込んでしまうことはありません。

Calibration — the gripper and the leaderCalibration — グリッパーとリーダー

The B601-DM does not use the Feetech wizard. Its Calibration page has cards that open read-only sweeps: you move the arm by hand and the app only watches.

B601-DMではFeetech用のウィザードは使いません。Calibrationページには、読み取り専用のスイープを開くカードがあります。アームは手で動かし、アプリは観測するだけです。

  • Follower gripper range — with the follower connected and torque off, sweep the jaw open to closed by hand. It stops the app from ever driving the gripper past its real end stop (a held jog past it once stalled the motor until a fuse blew). The dialog refuses to run while torque is on. Also reachable from Calibrate gripper range… in the Connection card. Reconnect the follower afterwards to apply the new range.
  • Follower gripper range — フォロワーを接続し、トルクをOFFにした状態で、ジョーを手で開から閉まで動かします。グリッパーが実際のエンドストップを超えて駆動されるのを防ぎます（ジョグを押し続けてモーターが失速し、ヒューズが切れた事例があります）。トルクONの間はダイアログが起動しません。ConnectionカードのCalibrate gripper range…からも開けます。適用にはフォロワーの再接続が必要です。
  • Leader — Star Arm 102 — with the leader connected, sweep every joint through its full travel. It replaces the vendor default ranges, which were off by up to 1.75× on the unit this was built with. Reconnect the leader afterwards.
  • Leader — Star Arm 102 — リーダーを接続し、全ジョイントを可動範囲いっぱいまで動かします。ベンダー既定の範囲（このアプリを作った個体では最大1.75倍ずれていました）を置き換えます。適用にはリーダーの再接続が必要です。
  • Zero position — a pointer to Set Zero in Motors and ids (section 4), because it works on the probed motor.
  • Zero position — Set Zeroは Probe したモーターに作用するため、Motors and ids（セクション4）への案内です。

The Star Arm 102 needs no calibration file to connect: its zero lives in the servos' own flash after a one-time set_origin_point(), equivalent to lerobot-calibrate's step for this leader. Connect it from the Control source tile Leader arm.

Star Arm 102は接続にキャリブレーションファイルを必要としません。ゼロ点は一度set_origin_point()を実行するとサーボ自身のフラッシュに保存されます（このリーダーに対するlerobot-calibrateの手順に相当）。コントロールソースのLeader armタイルから接続します。

04

Drive it動かす

Back on the stage. Connect the follower, turn torque on, choose who drives it. The app refuses to connect the SO-101 without a calibration file: there is no “just let me move it” mode.

ステージに戻ります。フォロワーに接続し、トルクをONにして、誰が動かすかを選びます。SO-101はキャリブレーションファイルなしでは接続できません（「とりあえず動かす」モードはありません）。

1

Connect and torque on接続とトルクON

In the Connection card pick the port and (SO-101) the calibration .json you saved, click Connect, then Torque ON. Torque-on seeds the goal with the current measured pose, so the arm holds still instead of lurching to an old target. On the B601-DM the connection uses the ids you assigned and the mode chosen in the Tune drawer. The red Stop in the top bar is always there.

Connectionカードでポートと（SO-101では）保存したキャリブレーション.jsonを選び、Connect、続けてTorque ONをクリックします。Torque ONは現在の実測姿勢を目標に設定するので、古い目標へ急に動かず、その場で保持します。B601-DMでは、割り当てたIDとTuneドロワーで選んだモードで接続します。トップバーの赤いStopは常に使えます。

2

Pick a control sourceコントロールソースを選ぶ

  • Manual — the Jog card.
  • Manual — Jogカード。
  • Gamepad — a standard Xbox-style controller, one stick axis per joint.
  • Gamepad — 標準的なXbox系コントローラー。スティックの各軸が1ジョイントに対応。
  • Keyboard — hold a key, the joint moves at a constant rate; release, it stops. Keys held when the window loses focus are released automatically. Keys (SO-101): Q/A shoulder_pan, W/S shoulder_lift, E/D elbow_flex, R/F wrist_flex, T/G wrist_roll, Y/H gripper.
  • Keyboard — キーを押している間、そのジョイントが一定速度で動き、離すと止まります。ウィンドウがフォーカスを失うと押下中のキーは自動で解放されます。キー（SO-101）：Q/A shoulder_pan、W/S shoulder_lift、E/D elbow_flex、R/F wrist_flex、T/G wrist_roll、Y/H gripper。
  • Leader arm — a second arm you move by hand drives the follower. See the next step.
  • Leader arm — 手で動かす2台目のアームがフォロワーを動かします。次のステップを参照。
3

Leader arm: standby, align, engageLeader arm：待機・位置合わせ・Engage

Choosing Leader arm connects the leader (SO-101: a second arm with its own port and calibration file; B601-DM: the Star Arm 102) but does not move the follower. The follower only tracks the leader after you press Engage teleop, and Engage is refused until the arms are close, so it can never snap to wherever the leader happens to be.

Leader armを選ぶとリーダーに接続しますが、フォロワーは動きません。Engage teleopを押して初めてフォロワーがリーダーを追従します。しかも両アームが近くなるまでEngageは拒否されるので、リーダーの現在位置へ急に飛ぶことはありません。

  • Engage is enabled only when the leader and the follower are both online, follower torque is ON, and every arm joint is within the Tolerance (default 10°, saved). The gripper is not part of the check.
  • Engageが有効になるのは、リーダーとフォロワーの両方がオンライン、フォロワーのトルクがON、かつすべてのアーム関節がTolerance（既定10°、保存されます）以内のときだけです。グリッパーは判定に含まれません。
  • While on standby the leader's pose is drawn as the ghost: move the leader until the ghost sits on the arm, then engage.
  • 待機中はリーダーの姿勢がゴーストで表示されます。ゴーストがアームに重なるまでリーダーを動かしてから、Engageします。
  • Teleop ends by itself on Stop, torque OFF, changing the control source, or either arm disconnecting. The button turns red as Disengage while it runs.
  • Stop、トルクOFF、コントロールソースの変更、どちらかのアームの切断で、遠隔操作は自動的に終了します。動作中、ボタンは赤いDisengageになります。
  • Gripper moves the wrong way (invert) flips the direction the relay treats as opening; Relay trim… adds a constant per-joint correction in degrees, most often needed on wrist_roll, whose zero is wherever the arm was held during Set middle. The two arms are calibrated independently, so the relay maps by fraction of each arm's own range, not raw degrees.
  • Gripper moves the wrong way (invert)は、リレーが「開く」とみなす向きを反転します。Relay trim…はジョイントごとに一定の補正角度（度）を加えます。wrist_rollで最も必要になります（ゼロ点がSet middle時の位置になるため）。2台は独立にキャリブレーションされているため、リレーは生の角度ではなく各アームの可動範囲に対する割合で対応づけます。
4

Teach a sequence (Waypoints drawer)シーケンスを記録する（Waypointsドロワー）

Record Waypoint snapshots the follower's current pose however it got there (hand-guided with torque off, leader-driven, or jogged). Record Grip is for a waypoint that must hold something: it snaps the gripper value to its nearest calibrated extreme so playback keeps commanding a target the object will not let it reach — that position error is the grip force. Reorder with Move Up / Down, then Play Sequence replays at a capped, eased speed (zero velocity and acceleration at each waypoint).

Record Waypointは、フォロワーの現在の姿勢を（トルクOFFで手で動かした場合も、リーダー操作もジョグも）そのまま記録します。Record Gripは何かを掴んで保持するウェイポイント用で、グリッパー値を最寄りのキャリブレーション端点にスナップします。再生中は対象物が許さない目標を出し続けるため、その位置誤差が把持力になります。Move Up / Downで順序を変え、Play Sequenceで上限速度付きの滑らかな動きで再生します（各ウェイポイントで速度・加速度ゼロ）。

  • Delay after selected waypoint + Set Delay on Selected pauses playback at that waypoint (e.g. hold a grip for 800 ms).
  • Delay after selected waypoint と Set Delay on Selected で、そのウェイポイントで再生を一時停止します（例：把持を800ms保持）。
  • Loop restarts from waypoint 1; unticking it mid-run lets the current pass finish. Speed (deg/s) can be changed live. Save… / Load… use .json files.
  • Loopは終了後にウェイポイント1から再開します。実行中に外すと現在の周回を終えて止まります。Speed（deg/s）は実行中も変更可能。Save… / Load…は.jsonを使います。
5

Read the servo telemetry (Telemetry drawer)サーボテレメトリを読む（Telemetryドロワー）

Current, load, velocity, voltage and temperature per joint at about 10 Hz, as a table or a live Graph. Watch a joint and field for running min / max / mean, and Start CSV Log to capture a session. The caption under the table says which values are cross-checked vendor conversions and which is an estimate (Vel (deg/s)*, marked with a star). On the SO-101, Target / Torque_Limit / Dead_Zone at the bottom tunes a joint's servo-side output cap and deadband; a joint that stalls under payload during playback usually just needs more Torque_Limit.

各ジョイントの電流・負荷・速度・電圧・温度を約10Hzで、テーブルまたはライブグラフで表示します。Watchでジョイントと項目を選ぶと最小・最大・平均が更新され、Start CSV Logでセッションを記録できます。テーブル下のキャプションに、検証済みのメーカー換算値と推定値（Vel (deg/s)*、星印）の区別が書かれています。SO-101では下部のTarget / Torque_Limit / Dead_Zoneでサーボ側の出力上限とデッドバンドを調整できます。再生中に負荷で失速するジョイントは、たいていTorque_Limitを上げるだけで解決します。

6

Tune the B601-DM (Tune drawer)B601-DMを調整する（Tuneドロワー）

  • Control mode — POS_VEL (default) uses the motor's own position / velocity loop. MIT sends fresh stiffness / damping (kp, kd) with every command: more responsive and compliant, but the gains must be tuned on the real arm, so start low (kp 5–10, kd 0.3–0.8). The mode applies on the next Connect; kp / kd apply live, with no reconnect and no torque cycling.
  • Control mode — POS_VEL（既定）はモーター自身の位置・速度ループを使います。MITは毎回のコマンドで剛性・減衰（kp、kd）を送ります。応答性が高く柔らかい反面、ゲインは実機で調整が必要なので低い値（kp 5〜10、kd 0.3〜0.8）から始めてください。モードは次回のConnectで反映され、kp / kdは再接続やトルクの入れ直しなしに即時反映されます。
  • Gain presets — Save as… stores the current kp / kd under a name, Load fills the boxes (and a connected MIT follower applies them at once), Delete removes one. Two are built in: "Gentle start" (the safe default) and "Holding start (stiffer, for load)" (kp 40 / kd 2.5 on joint2 and joint3). The second is a first guess for arms that must hold weight: load it with the arm supported and a hand near Stop, then tune each joint.
  • Gain presets — Save as…で現在のkp / kdを名前付きで保存、Loadで入力欄に反映（MIT接続中のフォロワーには即時適用）、Deleteで削除。組み込みは2つ：「Gentle start」（安全な既定値）と「Holding start (stiffer, for load)」（joint2・joint3は kp 40 / kd 2.5）。後者は荷重を保持するアーム向けの初期値の目安です。アームを支え、手をStopの近くに置いてから読み込み、ジョイントごとに調整してください。
  • Gravity compensation — in MIT the motor only receives kp / kd, so a loaded joint sags by about torque / kp. This adds the arm's own weight, computed from the MuJoCo model, as feed-forward torque so kp does not have to carry it. It is off at every start and stays locked until Check gravity model passes: with MIT mode, torque ON and the arm still, the model's holding torques must agree in sign (and roughly in size) with what the motors report. Then raise Amount slowly; it ramps in over a few seconds and is capped per joint (12 N·m for joints 1–3, 4 N·m for joints 4–6; none for the gripper). It switches off by itself on Stop, torque OFF or a disconnect, and then needs a new check.
  • 重力補償 — MITではモーターにkp / kdしか渡されないため、負荷のあるジョイントは約「トルク ÷ kp」だけ下がります。ここではMuJoCoモデルから計算したアーム自身の重さを、フィードフォワードトルクとして加え、kpが重さを支えなくて済むようにします。起動のたびにOFFで、Check gravity modelに合格するまでロックされています。MITモード・トルクON・アームが静止した状態で、モデルの保持トルクがモーターの報告値と符号（と大きさ）で一致する必要があります。その後Amountをゆっくり上げてください。数秒かけて立ち上がり、ジョイントごとに上限があります（joint1〜3は12 N·m、joint4〜6は4 N·m、グリッパーは対象外）。Stop・トルクOFF・切断で自動的にOFFになり、再度チェックが必要です。
  • Tracking — pick a joint: the chart shows the commanded target (dashed) against the measured position for the last 10 seconds, with peak error, settle time and overshoot of the latest step. It only reads data.
  • Tracking — ジョイントを選ぶと、直近10秒の指令目標（破線）と実測位置がチャートに表示され、最新のステップの最大誤差・整定時間・オーバーシュートが出ます。データを読むだけです。
  • Nudge ±5° — moves the chosen joint 5° from its current goal, clamped to its calibrated range. It is enabled only with the follower connected, torque ON, control source Manual, teleop not engaged and no sequence playing; otherwise the panel says why it is off.
  • Nudge ±5° — 選択したジョイントを現在の目標から5°動かします（キャリブレーション範囲内に制限）。フォロワー接続中、トルクON、コントロールソースがManual、遠隔操作が未Engage、シーケンス再生中でない場合のみ有効で、無効なときは理由が表示されます。
⚠

Raising kp on a joint that carries load can make it oscillate or hit hard. Change one joint at a time, in small steps, with a hand near Stop. A motor that faults after a stall stays latched until its power supply is cycled.

負荷のかかるジョイントでkpを上げると振動したり、強く当たったりすることがあります。1ジョイントずつ、少しずつ変更し、手をStopの近くに置いてください。失速後にフォルトしたモーターは、電源を入れ直すまでラッチされたままです。

Safety安全上の注意

This app is deliberately opinionated about not moving hardware it does not understand:

本アプリは、把握していないハードウェアを動かさないという方針を意図的に貫いています：

  • The SO-101 refuses to connect without a calibration file, and every commanded position is clamped to the calibrated range before it reaches a servo (and, on the B601-DM, to the calibrated joint range in degrees).
  • SO-101はキャリブレーションファイルなしでは接続を拒否し、送信されるすべての目標位置はサーボに届く前にキャリブレーション範囲へクランプされます（B601-DMでは度単位の較正済み範囲へ）。
  • Torque-on seeds the goal with the current measured pose, so re-enabling torque holds still.
  • Torque ONは現在の実測姿勢を目標に設定するため、トルクを入れ直しても動き出しません。
  • Stop (top bar or Ctrl+Shift+Space) turns follower torque off and returns control to Manual, so a leader that is still moving cannot make the arm jump when torque comes back.
  • Stop（トップバーまたはCtrl+Shift+Space）はフォロワーのトルクをOFFにしてManualに戻します。リーダーが動き続けていても、トルク再開時にアームが飛ぶことはありません。
  • Teleop needs an explicit, alignment-gated Engage and ends by itself on Stop, torque off, a source change or a disconnect.
  • 遠隔操作は、位置合わせを条件とする明示的なEngageが必要で、Stop・トルクOFF・ソース変更・切断で自動的に終了します。
  • Id assignment needs exactly one servo (or motor) on the bus; calibration steps are gated in order and finishing without a completed recording is refused.
  • ID割り当てはバス上に1台だけの状態で実行します。キャリブレーションは順序どおりにロックされ、記録が未完了のままFinishしようとすると拒否されます。
  • The B601-DM gripper range is measured by hand with torque off, and the calibration dialog will not run while torque is on.
  • B601-DMのグリッパー範囲はトルクOFFで手動測定し、トルクONの間はキャリブレーションのダイアログが起動しません。
⚡

The SO-101's servos need their own 5 V power supply: USB alone runs the serial adapter, not the motors. An arm that connects fine but never moves, with no error, almost always means this. For the B601-DM, never plug or unplug the motor connectors with power on.

SO-101のサーボには専用の5V電源が必要です。USB給電だけではシリアルアダプタが動くだけで、モーターは動きません。接続できるのに全く動かず、エラーも出ない場合は、ほぼこれが原因です。B601-DMでは、電源を入れたままモーターのコネクタを抜き差ししないでください。
